# D2SteamFix 한국어 설치 도우미

Destiny 2 의 전투 중 프레임 끊김을 줄여 주는 도구 **[D2SteamFix](https://github.com/d2checkpoint-com/D2SteamFix)** 를
쓰려면 Steam 실행 옵션 칸에 긴 명령을 직접 타이핑해야 합니다. 실제로 막히는 지점이 거기입니다.

이 도우미가 그 부분을 대신합니다. 게임 폴더를 찾아서, 실행 옵션 문자열을 만들고, 계정별 설정
파일(`localconfig.vdf`)에 대신 적어 줍니다. 되돌리기도 한 번에 됩니다.

Windows 전용이고, 설치 과정은 없습니다. 압축을 풀고 실행하면 끝입니다.

---

## 받아서 실행하기

**1. [`D2SteamFix 설치도우미.zip`](D2SteamFix%20설치도우미.zip) 을 내려받습니다.**
링크를 누르면 파일 페이지가 열리고, 거기서 내려받기 버튼을 누르면 됩니다.

**2. 압축을 풀기 전에 차단을 해제합니다.**
zip 파일 우클릭 → `속성` → 아래쪽 `차단 해제` 체크 → `확인`.

> 이 단계를 건너뛰면 안에 든 파일 전부로 차단 표시가 번져서, 실행할 때마다 보안 경고가 뜹니다.
> 압축을 푼 뒤에는 파일마다 따로 해제해야 하니 **풀기 전에** 하시는 편이 낫습니다.

**3. 압축을 풀고 `D2SteamFix 설치도우미.bat` 을 두 번 누릅니다.**
검은 창이 0.5초쯤 스쳤다가 도우미 창이 뜹니다. 그 창은 저절로 사라집니다.

---

## 도우미 창에서 하는 일

**1단계 · 설치 상태 확인** — Steam 폴더, Destiny 2 폴더, `steamfix.exe` 가 제자리에 있는지
찾아서 보여줍니다. 게임을 다른 드라이브로 옮겼거나 폴더를 못 찾으면 직접 지정할 수 있습니다.

**2단계 · `steamfix.exe` 준비** — **이 도우미는 `steamfix.exe` 를 포함하지 않습니다.**
제작자가 배포하는 공식 파일을 그대로 쓰도록 안내만 합니다. `다운로드 안내 열기` 를 누르면
받는 곳이 열리고, `게임 폴더 열기` 로 넣을 위치를 바로 열 수 있습니다.

**3단계 · 실행 옵션 설정** — 계정을 고르고 `자동으로 설정하기` 를 누르면 기록합니다. 이때
다음 작업을 합니다.

- 고치기 전에 `localconfig.vdf` 를 **백업**합니다 (최근 20개 보관, 위치는 창에 표시되고 눌러서 열립니다)
- Steam 이 켜져 있으면 먼저 종료를 제안합니다 (켜진 채로 고치면 Steam 이 나중에 덮어써서 설정이 사라집니다)
- 설정을 끝낸 뒤 `steamfix.exe`의 존재와 MZ 헤더를 확인합니다. 파일을 실행하지 않으며,
  실행 가능 여부나 백신 차단 여부를 판정하지 않습니다.

되돌리려면 `설정 되돌리기` 를 누르면 됩니다. 직접 넣던 다른 실행 옵션이 있었다면 그건 남겨 둡니다.

## 게임이 안 켜질 때

**대부분 백신입니다.** 그리고 경고창이 뜨는 경우보다 **아무 말 없이 막는 경우**가 더 골치입니다.
실제 사례에서 윈도우 보안은 경고만 하고 실행은 됐고, 국내 백신(V3)은 알림 없이 실행만
막았습니다. 사용자는 백신 문제인 줄도 모르고 "게임이 그냥 안 켜진다" 로만 겪습니다.

- **확인** — `작동 안 될 때`의 진단 정보, 게임 실행 후 `steamfix.log`, 백신의 차단 기록을
  함께 확인하세요. `파일 확인`은 존재와 헤더만 검사합니다. 최신 원본을 직접 실행하면
  복구 창이 열리므로 백신 진단용으로 실행하지 마세요.
- **윈도우 보안이 잡을 때** — 오탐입니다. 제작자가 마이크로소프트에 신고해 탐지는 이미
  지워졌고, 내 컴퓨터의 정의 파일이 오래되면 계속 뜹니다. 도우미의 `백신에 잡힐 때` 버튼이
  갱신 명령을 클립보드에 복사해 줍니다.
- **V3 · 알약 같은 국내 백신** — 위 명령은 효과가 없습니다. 그 백신의 격리소에서 파일을
  복원하고 검사 예외에 등록해야 합니다.

자세한 순서는 압축 안의 **`사용법 (필독).txt`** 에 적어 두었습니다
(받기 전에 미리 읽어 보실 수도 있습니다 → [`src/사용법 (필독).txt`](src/사용법%20(필독).txt)). `작동 안 될 때` 로 만든
진단 정보를 그대로 복사해 물어보셔도 됩니다 — 비밀번호 같은 개인 정보는 들어가지 않습니다.

## `steamfix.exe` 는 어디서 받나

원본의 [최신 GitHub 릴리스](https://github.com/d2checkpoint-com/D2SteamFix/releases/latest)에서
**Assets → steamfix.exe**를 받습니다. 도우미의 다운로드 버튼도 이 배포 방식으로 안내합니다.

---

## 알아두실 것

- 실행 옵션으로 `steamfix.exe` 를 거치게 되므로, **Steam 오버레이 관련 기능은 동작하지
  않습니다** (Steam Input, 게임 중 알림, 게임 녹화, 원격 플레이). 프레임 페이싱과 맞바꾸는
  부분입니다.
- 이 도우미는 **[D2SteamFix](https://github.com/d2checkpoint-com/D2SteamFix)(GPL-2.0) 의 코드를
  포함하지 않는 별개의 보조 도구**입니다. 원본을 고쳐 배포하는 것이 아니라, 공식 배포본을
  그대로 쓰도록 설정만 대신합니다. 프레임 개선 자체는 원본 제작자의 성과입니다.
- 고치는 파일은 Steam 의 `localconfig.vdf` 하나뿐이고, 그 안에서도 Destiny 2 의 실행 옵션
  항목만 건드립니다. 다른 게임 설정이나 계정 정보는 그대로 둡니다.

- 이 도우미 자체는 **[MIT 라이선스](LICENSE)** 입니다. 자유롭게 쓰고 고치고 다시 나눠 주셔도
  됩니다. 다만 원본 D2SteamFix 는 별개 프로젝트이고 GPL-2.0 이니, 그쪽 파일을 다룰 때는 그
  조건을 따르셔야 합니다.
