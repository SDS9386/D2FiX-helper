==========================================================
  D2SteamFix 설치 도우미 - 사용법 (필독)
==========================================================


[ 이게 뭔가요 ]

  데스티니 2를 스팀에서 할 때 프레임이 튀거나 끊기는 것을
  줄여주는 프로그램이 있습니다. 이름은 D2SteamFix 입니다.

  그걸 쓰려면 스팀 설정 칸에 게임 폴더 주소를 직접 타이핑해
  넣어야 해서 번거롭습니다. 이 도우미가 그 부분을 대신 합니다.


----------------------------------------------------------

[ 설치 순서 ]

  0. 압축을 풀기 전에 먼저,
     zip 파일 우클릭 - 속성 - 맨 아래 "차단 해제" 체크 - 확인.

     인터넷에서 받은 파일이라 붙는 표시입니다. 풀기 전에
     해제하지 않으면 안에 든 파일 전부로 번져서, 실행할 때마다
     보안 경고가 뜹니다.

  1. 압축을 풀고 "D2SteamFix 설치도우미.bat" 을 더블클릭합니다.
     관리자 권한은 필요 없습니다.

     ※ "Windows의 PC 보호" 파란 창이 뜨면
        [추가 정보] 를 누른 뒤 [실행] 을 누르면 됩니다.

  2. 1단계가 스팀과 데스티니 2 위치를 알아서 찾습니다.
     초록색 글씨면 정상입니다. 못 찾았다고 나오면
     [게임 폴더 직접 지정] 으로 알려주세요.

  3. 2단계에서 [다운로드 안내 열기] 를 누릅니다.
     열린 페이지의 Installation 항목에 파란색 steamfix.exe
     글씨가 있습니다. 그걸 누르면 파일이 받아집니다.

  4. [게임 폴더 열기] 로 열린 폴더에 받은 steamfix.exe 를
     옮겨 넣고, [다시 검사] 를 누릅니다.
     "준비 완료" 로 바뀌면 성공입니다.

  5. 3단계에서 [자동으로 설정하기] 를 누릅니다.
     스팀이 켜져 있으면 꺼도 되냐고 묻습니다 - 예를 누르세요.
     스팀이 켜진 상태에서는 설정이 저장되지 않습니다.

     ※ 자동 설정이 잘 안 되면 [복사해서 직접 넣기] 를 눌러,
        스팀 라이브러리에서 데스티니 2 우클릭 - 속성 -
        실행 옵션 칸에 Ctrl+V 로 붙여넣어도 됩니다.

  6. "설정이 끝났습니다" 창이 뜨면 다 된 겁니다.
     스팀을 다시 켜고 게임을 실행하면 적용되어 있습니다.

     도우미는 파일의 존재와 헤더만 확인합니다. 실행 가능 여부와
     백신 차단 여부는 확인하지 않습니다. 문제가 있으면 아래를 보세요.


----------------------------------------------------------

[ 게임이 안 켜질 때 ]

  대부분 백신입니다. 그리고 경고창이 뜨는 경우보다
  아무 말 없이 막는 경우가 더 골치입니다.

  실제 사례에서 윈도우 보안은 경고만 하고 실행은 됐고,
  국내 백신(V3)은 아무 알림 없이 실행만 막았습니다.
  그래서 백신 문제인 줄도 모른 채 "게임이 그냥 안 켜진다"
  로만 겪게 됩니다.

  확인 방법:
    [작동 안 될 때]의 진단 정보와 steamfix.log, 백신 차단 기록을
    함께 확인하세요. [파일 확인]은 파일 존재와 헤더만 확인합니다.
    최신 steamfix.exe 직접 실행은 복구 모드이므로 진단용으로 실행하지 마세요.


< 윈도우 보안(Windows Defender)이 잡는 경우 >

  오진입니다. 만든 사람이 마이크로소프트에 신고해서 탐지는
  이미 지워졌습니다. 그런데 내 컴퓨터의 백신 정의 파일이
  오래됐으면 지워진 예전 탐지가 계속 뜹니다.
  정의 파일을 갱신하면 해결됩니다.

  1. 시작 메뉴에서 "명령 프롬프트" 를 찾아 우클릭 -
     [관리자 권한으로 실행]

  2. 아래 세 줄을 한 줄씩 붙여넣고 각각 엔터를 칩니다.

     cd /d "C:\Program Files\Windows Defender"

     MpCmdRun.exe -removedefinitions -dynamicsignatures

     MpCmdRun.exe -SignatureUpdate

  3. 다 끝나면 steamfix.exe 를 다시 받아 주세요.

  도우미의 [백신에 잡힐 때] 를 누르면 위 명령이 클립보드에
  자동으로 복사됩니다.


< V3, 알약 등 국내 백신을 쓰는 경우 >

  위 명령은 윈도우 자체 백신용이라 국내 백신에는 효과가
  없습니다. 국내 백신은 마이크로소프트가 오탐으로 확인해
  해제한 것과 무관하게 자체 판단으로 막습니다.
  그래서 그 백신에서 직접 풀어야 합니다.

  1. 백신의 차단 기록이나 격리소에서 steamfix.exe 를 복원
  2. 검사 예외(제외) 목록에 게임 폴더나 steamfix.exe 를 추가
  3. 그래도 막히면 백신 제조사에 오탐 신고

  ※ 예외 등록은 그 파일을 검사 대상에서 빼는 것이라,
     출처를 믿을 수 있을 때만 하시는 게 맞습니다.
     찜찜하면 설치하지 않으셔도 됩니다.
     게임은 지금 그대로 돌아갑니다.

  ※ 증상 구분법
     파일은 그대로 있는데 게임만 안 켜지고 게임 폴더에
     steamfix.log 도 생기지 않았다면 실행이 막힌 것입니다.


< 백신이 아닌 경우 >

  * 아무 창도 안 뜬다
    -> 압축을 풀었는지 확인해 주세요.
       압축 안에서 바로 실행하면 동작하지 않습니다.

  * 설정은 했는데 게임이 아예 실행되지 않는다
    -> steamfix.exe 를 게임 폴더에 넣지 않고 설정만 한
       경우입니다. 파일을 넣거나 [설정 되돌리기] 를 누르세요.

  * "steamfix.exe : 실행 파일이 아닙니다" 라고 나온다
    -> 파일이 제대로 받아지지 않은 겁니다(브라우저가 오류
       페이지를 그 이름으로 저장한 경우). 다시 받아 덮어쓰세요.

  * 1단계에 "destiny2.exe 가 없습니다" 주황색 경고가 뜬다
    -> 게임을 다른 드라이브나 폴더로 옮긴 적이 있으면 예전
       자리의 빈 폴더를 잡을 수 있습니다.
       [게임 폴더 직접 지정] 으로 실제 위치를 알려주세요.
       그냥 설정하면 게임이 아예 켜지지 않습니다.

  * 1단계에 "쓰기 권한이 없습니다" 주황색 경고가 뜬다
    -> steamfix 는 게임 폴더에 기록 파일(steamfix.log)을
       만들어야 하고, 못 만들면 시작하자마자 종료됩니다.
       게임 폴더 우클릭 - 속성 - 보안 탭에서 본인 계정에
       "쓰기" 권한을 주세요.

  * 설정했는데 아무 변화가 없다
    -> 스팀을 껐다 켰는지 확인해 주세요. 그래도 안 되면
       3단계에서 계정을 잘못 고른 것일 수 있습니다.

  * 원인을 모르겠다
    -> [작동 안 될 때] 를 누르면 진단 정보가 나옵니다.
       그대로 복사해서 물어보시면 됩니다. 비밀번호 같은
       개인 정보는 들어가지 않습니다.


----------------------------------------------------------

[ 되돌리기 ]

  도우미를 다시 실행해서 [설정 되돌리기] 를 누르면 됩니다.
  원래 쓰시던 다른 실행 옵션이 있었다면 그건 지우지 않고
  그대로 남겨둡니다.

  지금 켜져 있는지는 3단계의 색으로 알 수 있습니다.

    초록색 - 작동 중. 게임이 D2SteamFix 를 거쳐 실행됩니다.
    회색   - 꺼짐. 게임과 스팀 오버레이가 평소대로입니다.
    빨간색 - 설정은 됐는데 steamfix.exe 가 없는 상태입니다.
             이대로 두면 게임이 아예 안 켜집니다.


----------------------------------------------------------

[ 꼭 알아두세요 ]

  * 적용하면 스팀 오버레이 관련 기능이 꺼집니다.

      Shift+Tab 오버레이 / 스팀 알림 / 게임 녹화 /
      원격 플레이 / 스팀 컨트롤러 설정

    원래 프로그램이 동작하는 방식이라 피할 수 없습니다.
    불편하면 언제든 되돌리면 됩니다.

  * 스팀 계정이 여러 개면 3단계에서 고를 수 있습니다.
    보통 맨 위(자동 로그인 계정)가 맞고, 실제로 게임하는
    계정에 설정해야 효과가 있습니다.

  * 여러 번 눌러도 창은 하나만 뜹니다. 일부러 그렇게 해
    두었습니다. 창이 둘이면 양쪽이 설정을 동시에 건드려
    꼬일 수 있습니다.


----------------------------------------------------------

[ 백업 ]

  고치는 파일은 스팀의 설정 파일(localconfig.vdf) 하나입니다.
  그 안에는 그 계정으로 설치한 다른 게임 설정도 함께 들어
  있어서, 고치기 전에 매번 원본을 통째로 복사해 둡니다.
  도우미가 건드리는 것은 데스티니 2의 실행 옵션 한 줄입니다.

  백업 위치는 3단계 맨 아래에 그대로 표시되고, 그 글씨나
  [백업 폴더 열기] 를 누르면 바로 열립니다. 최근 20개만
  두고 오래된 것부터 자동으로 지웁니다(하나에 250KB 정도).

  파일 이름은 이렇게 생겼습니다.

    localconfig-(계정번호)-(날짜)-(시각).vdf.bak

  손으로 복구해야 한다면, 스팀을 완전히 종료한 뒤
  (스팀 설치 폴더)\userdata\(계정번호)\config 에 백업 파일을
  복사하고 이름을 localconfig.vdf 로 바꿔 덮어쓰면 됩니다.
  보통은 [설정 되돌리기] 로 충분합니다.

권한 복구와 설정 제거 (원본 v1.1.0 기준)

게임을 정상 종료한 뒤 설정을 되돌리세요. 도우미는 탐지한 게임 폴더와
실행 옵션에 적힌 폴더에서 steamfix.dat 및 .tmp/.old 복구 파일을 확인하며,
실행 옵션이 이미 비어 있어도 복구 파일을 먼저 확인하며,
파일이 남아 있으면 복구 방법을 안내하고 실행 옵션 제거를 멈춥니다. 복구 파일은 직접 삭제하지 마세요.
게임을 종료해도 남아 있다면 최신 steamfix.exe 를 직접 열어 복구 창을 확인하세요.
승인하면 Steam과 게임을 종료하고 오버레이 파일을 다시 받으며, 필요시 Windows
권한 승인을 요청합니다. 복구 검증이 끝난 후 다시 도우미에서 설정을 되돌리세요.
도우미는 복구를 자동 실행하거나 복구 프로세스를 강제 종료하지 않습니다.

설정 되돌리기는 Steam 실행 옵션만 제거합니다. 오버레이 권한 복구 여부는
확인하지 않으며, 오버레이 문제가 계속되면 원본의 복구 안내를 확인하세요.
